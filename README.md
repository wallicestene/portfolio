# Wallicestene Waweru — Portfolio

Personal site of a software engineer in Nairobi. Live at [wallicestene-portfolio.netlify.app](https://wallicestene-portfolio.netlify.app/).

Built with React, Vite, GSAP and WebGL.

```bash
npm install
npm run dev     # local dev server
npm run build   # production build in dist/
```
